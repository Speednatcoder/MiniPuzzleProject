# MiniPuzzleProject
MiniPuzzleProject is a small project created during my Java learning.

## Assignment requirements:
- create an abstract class and two classes that inherit from the abstract class
- demonstrate ad-hoc polymorphism (method overloading) and polymorphism through method overriding. (Mark them with comments in the code)
- use upcasting and downcasting. (Mark them with comments in the code)
- demonstrate the program in action by creating objects and invoking methods.
